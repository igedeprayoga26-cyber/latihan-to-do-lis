# To Do List

## 📋 Deskripsi

To Do List adalah aplikasi web sederhana yang digunakan untuk mencatat dan mengelola daftar tugas atau kegiatan sehari-hari.

Website ini dibuat menggunakan **HTML, CSS, dan JavaScript**.

## ✨ Fitur

* ➕ Menambahkan tugas
* ✅ Menandai tugas yang sudah selesai
* ✏️ Mengedit tugas
* 🗑️ Menghapus tugas
* 📊 Menampilkan jumlah tugas
* 📌 Menampilkan jumlah tugas yang sudah selesai

## 🛠️ Teknologi yang Digunakan

* HTML
* CSS
* JavaScript

## 🚀 Cara Menjalankan

1. Download atau clone repository ini.
2. Buka folder project.
3. Buka file `index.html` menggunakan browser.
4. Website To Do List siap digunakan.
